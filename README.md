# Структура проекта

- `/modules`: модули приложения
- `/app`: инфраструктурные вещи, не связанные с бизнес-логикой
- `/shared`: общие компоненты, функции, стили для всего приложения


# Решение для UI - Volt

## Документация

- https://volt.primevue.org/vite/

## Плюсы

- легковесность
- полный контроль над стилями (unstyled-компоненты primevue без борьбы с их стилями)
- компоненты внутри проекта (максимум кастомизации)
- весь список переменных можно переназначить в css-файле

## Минусы

- сильная зависимость от tailwind, работать с которым крайне сложно без должного опыта и привычки
- верстка засорена обилием классов, что усложняет работу с браузерными devtools
- не хватает компонентов и их возможностей из коробки (нет компонента формы, нет всплывающего label у текстового поля, нет возможности у чекбокса заменить иконку)
- для получения полноценного компонента нужно комбинировать несколько (вместо указания пропса с именем иконки инпуту - добавлять компонент иконки и позиционировать самостоятельно ее)
- вся настройка стилей лежит в объекте внутри компонента, в т ч стилей размеров, что засоряет script
- слабая документация

## Вывод: 
Не подходит в нашем случае, т к гарантирует медленную разработку (команда не имеет опыта с tailwind и primevue + нужны более проработанные компоненты из коробки)
