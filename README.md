# Структура проекта

- `/modules`: модули приложения
- `/app`: инфраструктурные вещи, не связанные с бизнес-логикой
- `/shared`: общие компоненты, функции, стили для всего приложения

# Решение для UI - PrimeVue styled mode

## Документация

- https://primevue.org/theming/styled/

## Плюсы

- удобная система дизайн-токенов (нет необходимости перекрывать стили ::deep) 
- легко создать и настроить собственную тему
- cssLayer.order в настройках плагина позволяет поставить свои стили выше стилей библиотеки, что позволяет избежать конфликтов и important!
- большая библиотека компонентов, есть все необходимое
- компонент разделен на несколько частей, что обеспечивает более гибкую кастомизацию
- хорошая поддержка typescript

## Минусы

- достаточно высокий порог входа для дизайн-токенов (команда с библиотекой раньше не работала)
- для точечного изменения стилей нужно искать нужный токен, а не исправить css напрямую
- доступных токенов недостаточно, а добавление своих неудобно и перегружает код
- скорее всего придется смешивать токены и css, что дает 2 источника стилей, т е неудобно
- доп абстракция между компонентом и итоговым css

## Вывод:
Стоит рассмотреть из-за больших возможностей кастомизации, но есть риск замедлить разработку, т к нужно будет время на обучение.
